# ReadMe v1.0.0 发布说明

> 发布日期：2026-11-06
> 适用版本：`1.0.0`
> 运行环境：Windows 10/11、WebView2；源码开发需要 Python 3.11.9；Edge TTS 联网

## 支持平台

- **B 站**：完整链路支持。公开弹幕、登录态、朗读、浮窗、独立监看、历史场次、趋势/对比/复盘与 JSON/CSV 导出。
- **抖音**：支持公开弹幕、账号登录、礼物/入场解析和历史隔离；礼物只按单条钻石显示，不汇总人民币。抖音没有 SC/舰长等价能力，相关界面和报告明确显示“平台未提供”，不伪造 `¥0.00`。

## 版本内容

- 配置 schema v3、历史库 schema v4 与成对配置迁移/备份。
- 浮窗工作台与独立监看窗口的小 / 中 / 大 / 超大界面预设。
- 晨光 / 夜航 / 跟随系统外观、点阵背景和自定义主题。
- 本机历史场次、按日/小时/周趋势、同房间单基准与多基准对比、事实型复盘和分析报告导出。
- 导出文件管理支持“全部时间 / 自然周”筛选，周外文件不进入清理候选。
- 凭证使用 Windows DPAPI；DPAPI 不可用时明确提示 `plain1:` 可逆编码降级。
- 配置解密失败 fail-closed：不登录、不清空原密文、不覆盖原配置文件。

## 已知限制

- Edge TTS 依赖微软在线服务，断网无法合成；不是完全离线工具。
- 抖音匿名状态下的部分礼物推送可能受平台风控影响；发布前已在公开开播房间完成 15 分钟稳定性 soak（1786 条消息、0 次错误）。
- 抖音礼物按钻石显示，平台金额口径不与 B 站人民币字段混算。
- 在线人数、平台营收和观众活跃率不纳入计算；历史只保存本机聚合数据，不保存弹幕正文、用户名或 UID。
- 高密度弹幕会按队列上限丢弃最旧条目；这是有界降级，不代表收到全量消息。
- 浮窗、监看和主工作台的多显示器布局受 Windows DPI 与窗口捕获软件影响，首次使用需在本机确认位置。

## 安装与升级

### 便携包

1. 下载 `ReadMe-v1.0.0-standalone.zip` 并解压到任意目录。
2. 双击 `ReadMe.exe`。不需要安装 Python、pip 或 `.venv`。
3. 需要 Windows 10/11 和 WebView2；语音合成需要联网。

### 从源码运行（开发用途）

从仓库根目录执行：

```powershell
cd <项目目录>
py -3.11 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-v1.txt
```

依赖清单固定 Python 3.11.9 下的运行时版本，并包含 vendored `blivedm` 源码。

升级前请成对备份：

- `config.json`
- `config.legacy.json`
- `data/history.sqlite3`（如存在）

旧配置首次启动会在校验通过后迁移；迁移或写盘失败时进入只读安全模式，不覆盖原文件。

## 回滚

1. 关闭 ReadMe，确认主窗口、监看窗口和浮窗进程均已退出。
2. 成对恢复升级前的 `config.json` 与 `config.legacy.json`。若使用 v2→v3 迁移，优先使用生成的 `config.v2.bak` 与 `config.legacy.v2.bak`。
3. 恢复对应的历史库备份（如有），再启动旧版本。
4. 旧版本不支持的 schema 会按只读安全模式处理，不静默降级写回；确认兼容后再继续使用。
